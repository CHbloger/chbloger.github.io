# DevTools Pro

A comprehensive collection of developer tools and utilities in a single professional web interface.

## Features

1. **JSON Formatter & Validator**: Format, minify, and validate JSON data.
2. **Image to WebP Converter**: Client-side image conversion to WebP format.
3. **Base64 Encoder/Decoder**: Handle text and image Base64 operations.
4. **Regex Tester**: Test regular expressions with real-time highlighting and presets.
5. **Markdown to HTML Converter**: Convert Markdown to HTML with preview.
6. **Color Palette Extractor**: Extract dominant colors from uploaded images.
7. **QR Code Generator**: Generate custom QR codes.
8. **AdSense Integration**: Ready-to-use placeholders for AdSense banners.

## Usage

Simply open `index.html` in a web browser. No server setup required for basic features.
For local development, it is recommended to serve with a local server (e.g., `python3 -m http.server`) to avoid CORS issues with some browser features (like Canvas `toDataURL` in some contexts, though mostly fine with file uploads).
