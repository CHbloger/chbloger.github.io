Base64 인코딩이란?

Base64는 이진 데이터(Binary Data)를 ASCII 문자열로 변환하는 인코딩 방식입니다. 주로 이메일 첨부 파일 전송이나 HTML/CSS 내에 이미지를 직접 삽입(Data URI Scheme)할 때 사용됩니다. 서버와의 불필요한 HTTP 요청을 줄이기 위해 작은 아이콘이나 이미지를 Base64 문자열로 변환하여 코드에 포함시키는 것이 일반적입니다.

DevTools Pro의 Base64 도구는 텍스트와 이미지 두 가지 모드를 지원합니다. 텍스트 모드에서는 일반 문자열을 안전하게 Base64 포맷으로 변환하거나 그 반대로 복원할 수 있으며, 한글(UTF-8) 처리도 완벽하게 지원합니다. 이미지 모드에서는 파일을 업로드하면 즉시 `img src` 태그에 사용할 수 있는 Base64 문자열을 생성해줍니다.

활용 사례

  • 웹 개발: 작은 이미지를 CSS나 HTML 파일 내에 직접 포함시켜 로딩 속도 최적화.
  • 데이터 전송: 바이너리 데이터를 텍스트 기반 프로토콜(JSON, XML 등)에 포함시켜 전송할 때.
  • 보안 및 난독화: 평문 데이터를 간단하게 인코딩하여 가독성을 낮춤 (암호화는 아닙니다).
