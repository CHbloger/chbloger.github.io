JSON 포맷터 & 검증기

못생긴 JSON 데이터를 예쁘게 정렬하고 문법 오류를 검사합니다. 압축 기능도 지원합니다.
WebP 이미지 변환기

JPG, PNG 이미지를 구글이 권장하는 차세대 포맷 WebP로 변환하여 로딩 속도를 개선하세요.
Base64 인코더/디코더

텍스트나 이미지 파일을 Base64 문자열로 인코딩하거나 디코딩하여 데이터를 안전하게 전송하세요.
정규표현식 테스트

복잡한 정규식 패턴을 실시간으로 테스트하고, 이메일/전화번호 등 유용한 프리셋을 활용하세요.
Markdown → HTML

마크다운 문법으로 작성한 글을 HTML 코드로 즉시 변환하여 블로그나 웹사이트에 적용하세요.
컬러 팔레트 추출기

이미지를 업로드하면 주요 색상 코드를 추출하여 아름다운 컬러 팔레트를 만들어줍니다.
QR코드 생성기

URL, 텍스트, 와이파이 정보 등을 담은 QR코드를 생성하고 커스터마이징하여 다운로드하세요.
